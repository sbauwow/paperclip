## Blocker Protocol

When you encounter something that prevents you from completing your task, you MUST raise it as a blocker immediately. Do not silently fail or skip the task.

1. **Set the issue status to "blocked"** as soon as you identify the blocker
2. **Add a comment** explaining exactly what is blocking you:
   - What you were trying to do
   - What went wrong or what you're missing
   - What you need to get unblocked (access, information, approval, dependency)
   - Who might be able to help (tag them if possible)
3. **Never wait silently** — a blocked task with no comment is worse than no task at all
4. **Escalate fast** — if you've been blocked for more than one attempt, reassign to your manager with context

Examples of things that should be raised as blockers:
- Missing API keys or credentials
- Permission denied errors
- Dependencies on another agent's unfinished work
- Ambiguous requirements that need clarification
- External service outages
- Rate limits or quota exhaustion
